# Verbix v1

Verbix v1 is a Linux x86_64 desktop app. The Rust/Tauri shell is the
long-lived process: it starts at login in the tray, owns the global toggle
shortcut, and supervises the Python voice service, which keeps the existing
runtime, voice stack, tools, and IPC. A panel opened from the tray shows floor
state, live captions, and background tasks; completed worker results are
spoken in the same voice and appear as completed rows. The Linux artifact is
an AppImage that runs from wherever the user puts it and writes its data to
`~/.verbix`; first run asks for the provider key, downloads the speech model,
and offers autostart. macOS and Windows are seams to fill in later, not v1
releases. Out of v1: settings UI, overlay, auto-update, signing, store
distribution, and any runtime redesign.
