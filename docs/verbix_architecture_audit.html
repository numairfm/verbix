Executive Summary & Architectural Diagnosis

Verbix was designed around a clean invariant: three roles (Foreground, Announcer, Worker) running on a single engine, differentiated strictly by YAML configuration. Instead, the implementation drifted into four overlapping agent classes totaling ~1,550 lines of duplicated loop logic: VoiceAgent (src/verbix/agent/voice.py), WorkerAgent (src/verbix/agent/worker.py), AnnouncerAgent (src/verbix/agent/announcer.py), and legacy DefaultAgent (src/verbix/agent/agents/default.py).

When driven by a frontier reasoning model, prompt instructions masked structural gaps in the loop. When driven by a fast, literal 8B-class model (Gemini 3.5 Flash-Lite), every unguarded seam failed simultaneously in a 5-stage cascade.

Root Cause Breakdown: Prompting vs. Loop Mechanics vs. Dual-Agent Drift

1. Prompting Fallacy Soft Guard

Security and loop invariants were delegated to prose rules in voice.yaml and worker.yaml (e.g., "status and cancel only on request", "keep you inside the workspace").

Why it failed: 8B/Flash-Lite models under ambiguity optimize for action completion over negative constraints. Prompting guides intent; code must enforce invariants (tool call caps, path containment, objective validation).

2. Loop Mechanics In-Band Signaling

TurnComplete(final_text: str) in core/events.py:45 conflates two orthogonal concepts: spoken assistant prose and machine termination status ("RepeatedToolCall", "LimitsExceeded", "TimeExceeded").

Why it failed: runtime/announcer.py:183 patched a one-off filter for LimitsExceeded, while SpeechOutput.emit() and Runtime.submit() remained completely exposed to RepeatedToolCall.

3. Multi-Agent Drift 4 Divergent Loops

VoiceAgent, WorkerAgent, AnnouncerAgent, and DefaultAgent each re-implement template rendering, compaction, tool dispatch, cost tracking, and repeat detection differently.

Why it failed: Fixes landed in one class (e.g., side-effect shielding in VoiceAgent, consecutive tool error feedback in WorkerAgent) while sibling classes rotted.

Why Streaming vs. Batching Divergence Created Unhandled Edge Cases

The Double-Adaptation Paradox (runtime/foreground.py:287-331 & agent/worker.py:169-175):
ProviderStreamAdapter.query_stream() already streams canonical events from the provider. Yet because WorkerAgent.step() was written as a synchronous-style batch loop calling self.model.query(), ProviderStreamAdapter.query() consumes the entire async stream into memory, discards live TextDelta and ToolCallDelta events, and returns a static dictionary.
  • Broken Live Telemetry: Because WorkerAgent batches model output, WorkerTask (runtime/worker.py:131) had to bolt on a side-channel session.on_event callback that only fires after the model turn finishes—starving --show-worker-turns of real-time token and tool-argument streaming.
  • Divergent Repeat Circuit Breakers: When a tool repeats 3 times in VoiceAgent, it immediately aborts the turn with TurnComplete(final_text="RepeatedToolCall") (voice.py:416). When a tool repeats 3 times in WorkerAgent, it injects a synthetic ToolResult("Error: Tool '...' was called 3 times consecutively...") (worker.py:288) and keeps looping.
  • Dual Runner Harness in WorkerTask._run: Because the codebase couldn't decide whether a worker session exposes .run(), .step_stream(), or .step(), runtime/worker.py:126-207 contains an 80-line reflection maze checking has_run, has_step_stream, and hasattr(session, "step") with three separate termination checks.

The "One Engine, Three Flavors" Architecture

We replace VoiceAgent, WorkerAgent, AnnouncerAgent, and DefaultAgent with a single ~220-line Agent class in src/verbix/agent/engine.py. Every agent streams events via step_stream(); flavor differences are expressed strictly as declarative fields on AgentConfig.

Standardized Event & Exit Semantics

The root cause of the "RepeatedToolCall" audio leak was stuffing machine exit codes into TurnComplete.final_text. We standardize src/verbix/core/events.py so that final_text exclusively contains human-facing prose, while loop termination state rides on explicit typed fields:

The Golden Event Rule: TurnComplete.final_text is strictly spoken/displayable assistant text. If a turn terminates due to a circuit breaker (exit_reason="repeated_tool_call" | "limits_exceeded" | "time_exceeded" | "format_error"), final_text is either "" or a fixed, user-safe spoken fallback string—never an CamelCase exception identifier.
03

Bulletproofing the Voice / Intent Seam

A. STT Noise Hardening Intent Gate

Problem: Whisper/Sherpa STT frequently produces phonetic near-misses on casual speech ("Hey what's up" → "He wits up."). Fast models hallucinate that garbled nouns are files or system processes and call spawn.

Defense (Two-Tier):

  • Prompt Invariant (voice.yaml): Explicitly instruct the model that input comes from live speech-to-text; short phonetic fragments, greetings, or nonsensical phrases without a clear action verb must be answered conversationally or clarified—never delegated to spawn.
  • Structural Gate in SpawnTool: Reject objectives that frame transcription uncertainty as an investigation (e.g., matching "figure out what '...' refers to", "check system logs for clues") and return a tool error instructing the Foreground to ask the user for clarification.
B. One-Shot Tool Discipline No Polling

Problem: When the user asked "What?", the foreground called status(), saw the task was still running, and immediately called status() twice more in the same turn.

Defense (Engine-Level Cap):

  • Per-Turn Tool Call Budget: Foreground sets max_calls_per_tool_per_turn={"status": 1, "cancel": 1}.
  • Dynamic Schema Pruning: Once status has been called once in a foreground turn, the engine removes status from tool_defs on the subsequent follow-up model call in that turn (or blocks re-invocation with a directive observation), forcing the model to speak the status snapshot to the user immediately.
C. Audio Sanitization Firewall Zero Leak

Problem: SpeechOutput.emit(TurnComplete) trusted event.final_text unconditionally and synthesized "RepeatedToolCall".

Defense (Defense-in-Depth):

  • Source Separation: Engine sets TurnComplete(final_text="", exit_reason="repeated_tool_call", is_error=True). If already-delivered text is empty on a foreground error exit, the engine emits a fixed spoken recovery phrase.
  • Sink Firewall (SpeechOutput): Drops any TurnComplete where is_error=True or exit_reason != "ok", and strips any residual internal CamelCase/sentinel tokens before _sentences() queues TTS frames.
04

Worker Sandboxing & Objective Integrity

In the current codebase, TOOL_CATALOG["bash"] = lambda runtime: BashTool() (src/verbix/tools/__init__.py:62) initializes BashTool(sandboxed=False). Even worse, when sandboxed=True is used on Linux, bwrap still mounts /proc and allows reading global process tables unless restricted, and fails on platforms without bwrap.

1. Workspace-Contained Bash Runner Mandatory Sandbox
  • Default-On Sandboxing: Flip BashTool(sandboxed=True) by default in TOOL_CATALOG and BashTool.__init__.
  • Command & Path Guard (Cross-Platform Seam): Before spawning a shell on any OS (Linux, macOS, Windows), validate the command string against workspace escape and system-inspection vectors:
    • Block root/parent traversal outside context.workspace (e.g., absolute paths outside workspace//tmp, find /, .. escapes).
    • Block system log, process, and credential/history harvesting (journalctl, dmesg, /var/log, ps aux, ~/.bash_history, ~/.zsh_history, ~/.ssh, env/printenv).
  • Sanitized Subprocess Environment: Strip host HOME (point HOME and TMPDIR to the worker's .verbix/tasks/<id> scratch directory), set HISTFILE=/dev/null, and redact host API keys from the child environment.
  • OS Isolation Layer: Use bwrap (with --unshare-pid so /proc only shows the worker's own PID namespace) on Linux when available, sandbox-exec on macOS when available, and enforce the deterministic Command & Path Guard + isolated HOME across all three platforms.
2. Objective Integrity at the spawn Boundary Zero Speculation
  • Why Foreground Speculation Happens: When the user says something ambiguous, a fast model tries to be "helpful" by synthesizing a detective mission for the worker: "Figure out what X refers to, or check system logs / workspace for recent clues."
  • Objective Sanitizer in SpawnTool.execute():
    • Rejects speculative meta-objectives (regex guard catching figure out what .* refers to, check system logs, journalctl, bash_history, recent clues).
    • Returns an immediate ToolResult(..., is_error=True) telling the Foreground: "Error: Objective contains speculative system inspection or unresolved user intent. Ask the user to clarify what they meant in one short sentence."
  • Result: Even an 8B model cannot launch a fishing expedition on a misheard utterance; the tool error forces a polite 1-sentence voice clarification on the same turn.

import asyncio
import json
import logging
import platform
import time
from collections.abc import AsyncIterator
from dataclasses import dataclass
from typing import Any, Literal

from jinja2 import StrictUndefined, Template
from pydantic import BaseModel, Field

from verbix.agent.tools.registry import ToolRegistry
from verbix.agent.utils.compaction import compact_messages
from verbix.agent.utils.history import CANCELLED_TOOL_CONTENT, validate_and_repair_history
from verbix.tools.base import ToolResult, parse_lenient_json
from verbix.voice.segments import split_chunks

ExitReason = Literal[
    "ok",
    "terminal_tool",
    "repeated_tool_call",
    "limits_exceeded",
    "time_exceeded",
    "format_error",
    "exception",
]


@dataclass(frozen=True)
class AgentEvent:
    pass


@dataclass(frozen=True)
class TextDelta(AgentEvent):
    text: str


@dataclass(frozen=True)
class ThoughtDelta(AgentEvent):
    thought: str


@dataclass(frozen=True)
class ToolCallDelta(AgentEvent):
    index: int = 0
    call_id: str | None = None
    name: str | None = None
    arguments_delta: str = ""


@dataclass(frozen=True)
class ToolCallStarted(AgentEvent):
    call_id: str
    tool_name: str
    arguments: dict[str, Any]


@dataclass(frozen=True)
class ToolCallFinished(AgentEvent):
    call_id: str
    observation: str
    is_error: bool = False


@dataclass(frozen=True)
class TurnComplete(AgentEvent):
    final_text: str
    exit_reason: ExitReason = "ok"
    is_error: bool = False


class AgentConfig(BaseModel):
    """Unified configuration driving Foreground, Announcer, and Worker on one engine."""

    system_template: str = ""
    instance_template: str = "{{task}}"
    tools: list[str] = Field(default_factory=list)
    tool_choice: str | None = None
    step_limit: int = 0
    cost_limit: float = 3.0
    wall_time_limit_seconds: int = 0
    turn_scoped_limits: bool = True
    max_context_tokens: int = 16000
    repeat_limit: int = 3
    max_consecutive_format_errors: int = 3
    # Flavor toggles:
    speech_chunking: bool = False
    require_tool_before_finish: bool = False
    max_calls_per_tool_per_turn: dict[str, int] = Field(default_factory=dict)
    spoken_error_fallback: str = "Sorry, I ran into a snag. Could you say that again?"


class Agent:
    """Single unified agent engine for Foreground, Announcer, and Worker."""

    def __init__(
        self,
        model: Any,
        tools: ToolRegistry | None = None,
        config: AgentConfig | dict[str, Any] | None = None,
        env: Any = None,
    ) -> None:
        self.model = model
        self.tools = tools
        self.env = env
        self.config = config if isinstance(config, AgentConfig) else AgentConfig(**(config or {}))
        self.messages: list[dict[str, Any]] = []
        self.cost: float = 0.0
        self.turn_cost: float = 0.0
        self.n_calls: int = 0
        self.turn_calls: int = 0
        self._tools_executed: int = 0
        self._start_time: float = time.time()
        self._delivered_text: str = ""
        self.extra_template_vars: dict[str, Any] = {}
        self.logger = logging.getLogger("verbix.agent")

    def _render(self, template_str: str, **kwargs: Any) -> str:
        if not template_str:
            return ""
        ctx = {**platform.uname()._asdict(), **self.config.model_dump(), **self.extra_template_vars, **kwargs}
        try:
            return Template(template_str, undefined=StrictUndefined).render(**ctx)
        except Exception:
            return Template(template_str).render(**ctx)

    def _active_tool_defs(self, per_turn_counts: dict[str, int]) -> list[dict[str, Any]] | None:
        if self.tools is None or self.config.tool_choice == "none":
            return None
        allowed = [
            name for name in (self.config.tools or list(self.tools._handlers))
            if per_turn_counts.get(name, 0) < self.config.max_calls_per_tool_per_turn.get(name, 999999)
        ]
        if not allowed:
            return None
        defs = self.tools.get_definitions(allowed)
        return defs or None

    async def _execute_tool(self, name: str, args: dict[str, Any]) -> ToolResult:
        if self.tools is None:
            return ToolResult(f"Error: Tool '{name}' is not available.", is_error=True)
        try:
            res = await self.tools.aexecute(name, args)
            self._tools_executed += 1
            return res if isinstance(res, ToolResult) else ToolResult(str(res))
        except Exception as e:
            return ToolResult(f"Error executing '{name}': {e}", is_error=True)

    async def step_stream(self, user_input: str | None = None) -> AsyncIterator[AgentEvent]:
        if self.config.turn_scoped_limits:
            self.turn_calls = 0
            self.turn_cost = 0.0

        is_initial = not any(m.get("role") == "user" for m in self.messages)
        if not self.messages and self.config.system_template:
            sys_text = self._render(self.config.system_template)
            if sys_text:
                self.messages.append({"role": "system", "content": sys_text})

        if user_input is not None:
            content = (
                self._render(self.config.instance_template, task=user_input)
                if is_initial and self.config.instance_template
                else user_input
            )
            self.messages.append({"role": "user", "content": content})

        repeat_history: list[tuple[str, str]] = []
        per_turn_counts: dict[str, int] = {}
        format_errors = 0

        try:
            while True:
                calls = self.turn_calls if self.config.turn_scoped_limits else self.n_calls
                spent = self.turn_cost if self.config.turn_scoped_limits else self.cost
                if (0 < self.config.step_limit <= calls) or (0 < self.config.cost_limit <= spent):
                    yield TurnComplete(final_text=self._delivered_text, exit_reason="limits_exceeded", is_error=True)
                    return
                if 0 < self.config.wall_time_limit_seconds <= int(time.time() - self._start_time):
                    yield TurnComplete(final_text=self._delivered_text, exit_reason="time_exceeded", is_error=True)
                    return

                self.n_calls += 1
                self.turn_calls += 1
                self._delivered_text = ""
                self.messages[:] = compact_messages(self.messages, max_tokens=self.config.max_context_tokens)

                tool_defs = self._active_tool_defs(per_turn_counts)
                stream_kwargs: dict[str, Any] = {}
                if self.config.tool_choice == "none" or tool_defs is None:
                    stream_kwargs["tool_choice"] = "none"
                elif self.config.tool_choice:
                    stream_kwargs["tool_choice"] = self.config.tool_choice

                accumulated_tcs: dict[int, dict[str, Any]] = {}
                buffered_deltas: list[TextDelta] = []
                pending_text = ""
                released_text = ""
                has_tool_calls = False

                async for event in self.model.query_stream(self.messages, tools=tool_defs, **stream_kwargs):
                    if isinstance(event, TextDelta):
                        if has_tool_calls:
                            continue
                        if not self.config.speech_chunking:
                            self._delivered_text += event.text
                            released_text += event.text
                            yield event
                        else:
                            buffered_deltas.append(event)
                            pending_text += event.text
                            if len(split_chunks(pending_text)) > 1:
                                for d in buffered_deltas:
                                    self._delivered_text += d.text
                                    yield d
                                released_text += pending_text
                                pending_text = ""
                                buffered_deltas.clear()
                    elif isinstance(event, ThoughtDelta):
                        yield event
                    elif isinstance(event, ToolCallDelta):
                        has_tool_calls = True
                        buffered_deltas.clear()
                        pending_text = ""
                        tc = accumulated_tcs.setdefault(
                            event.index,
                            {"call_id": event.call_id or f"call_{event.index}", "name": "", "arguments": ""},
                        )
                        if event.call_id:
                            tc["call_id"] = event.call_id
                        if event.name:
                            tc["name"] = event.name
                        if event.arguments_delta:
                            tc["arguments"] += event.arguments_delta

                if not has_tool_calls:
                    for d in buffered_deltas:
                        self._delivered_text += d.text
                        yield d
                    buffered_deltas.clear()

                    # Worker guard: require at least one tool call before concluding
                    if self.config.require_tool_before_finish and self._tools_executed == 0:
                        format_errors += 1
                        if format_errors >= self.config.max_consecutive_format_errors:
                            yield TurnComplete(final_text="", exit_reason="format_error", is_error=True)
                            return
                        self.messages.append({"role": "assistant", "content": self._delivered_text})
                        self.messages.append({
                            "role": "user",
                            "content": "You have not executed any tools yet. Execute a tool to perform the task.",
                        })
                        continue

                    self.messages.append({"role": "assistant", "content": self._delivered_text})
                    yield TurnComplete(final_text=self._delivered_text, exit_reason="ok", is_error=False)
                    return

                # Prepare and record assistant tool-call message
                calls_to_run: list[dict[str, Any]] = []
                for idx in sorted(accumulated_tcs):
                    raw = accumulated_tcs[idx]
                    raw_str = raw["arguments"]
                    try:
                        parsed = json.loads(raw_str) if raw_str.strip() else {}
                    except json.JSONDecodeError:
                        parsed = parse_lenient_json(raw_str)
                    calls_to_run.append({
                        "call_id": raw["call_id"],
                        "name": raw["name"],
                        "args": parsed if isinstance(parsed, dict) else {},
                        "args_str": raw_str,
                    })

                self.messages.append({
                    "role": "assistant",
                    "content": released_text or None,
                    "tool_calls": [
                        {
                            "id": c["call_id"],
                            "type": "function",
                            "function": {"name": c["name"], "arguments": c["args_str"]},
                        }
                        for c in calls_to_run
                    ],
                })

                # Execute tools with per-turn cap and repeat circuit breaker
                for c in calls_to_run:
                    name, call_id, args = c["name"], c["call_id"], c["args"]
                    cap = self.config.max_calls_per_tool_per_turn.get(name)
                    if cap is not None and per_turn_counts.get(name, 0) >= cap:
                        res = ToolResult(
                            f"Tool '{name}' already called in this turn. Answer the user directly using the previous result.",
                            is_error=True,
                        )
                    else:
                        per_turn_counts[name] = per_turn_counts.get(name, 0) + 1
                        yield ToolCallStarted(call_id=call_id, tool_name=name, arguments=args)
                        if self.tools and self.tools.is_side_effecting(name):
                            pending = asyncio.ensure_future(self._execute_tool(name, args))
                            try:
                                res = await asyncio.shield(pending)
                            except asyncio.CancelledError:
                                res = await pending
                                self.messages.append({
                                    "role": "tool",
                                    "tool_call_id": call_id,
                                    "name": name,
                                    "content": res.observation,
                                })
                                raise
                        else:
                            res = await self._execute_tool(name, args)

                    yield ToolCallFinished(call_id=call_id, observation=res.observation, is_error=res.is_error)
                    self.messages.append({
                        "role": "tool",
                        "tool_call_id": call_id,
                        "name": name,
                        "content": res.observation,
                    })

                    sig = (name, json.dumps(args, sort_keys=True))
                    repeat_history.append(sig)
                    if (
                        len(repeat_history) >= self.config.repeat_limit
                        and len(set(repeat_history[-self.config.repeat_limit:])) == 1
                    ):
                        yield TurnComplete(
                            final_text=self._delivered_text,
                            exit_reason="repeated_tool_call",
                            is_error=True,
                        )
                        return

                    if res.is_terminal:
                        yield TurnComplete(
                            final_text=res.observation,
                            exit_reason="terminal_tool",
                            is_error=res.is_error,
                        )
                        return

        except asyncio.CancelledError:
            self.messages[:] = validate_and_repair_history(self.messages, delivered_text="")
            raise
        except Exception as e:
            self.logger.warning("Agent turn failed: %s", e)
            self.messages[:] = validate_and_repair_history(self.messages, delivered_text=self._delivered_text)
            note = self.config.spoken_error_fallback
            self.messages.append({"role": "assistant", "content": note})
            yield TurnComplete(final_text=note, exit_reason="exception", is_error=True)

class SpawnTool:
    name: str = "spawn"
    side_effecting: bool = True
    description: str = (
        "Starts an autonomous background worker for a concrete user-requested task. "
        "Never call spawn on ambiguous speech, greetings, or suspected transcription errors."
    )

    def __init__(self, runtime: object) -> None:
        self.runtime = runtime

    async def execute(self, args: dict[str, object], context: ToolContext) -> ToolResult:
        objective = str(args.get("objective", "")).strip()
        if len(objective) < 8:
            return ToolResult("error: objective is too vague to spawn background work.", is_error=True)

        if _SPECULATIVE_OBJECTIVE_RE.search(objective):
            return ToolResult(
                "error: objective contains speculative system inspection or unresolved speech ambiguity. "
                "Do not spawn a worker to guess what a phrase means; ask the user to clarify in one short sentence.",
                is_error=True,
            )

        task_id = await self.runtime.spawn(objective)
        return ToolResult(f"{task_id} started in background.")

# Deterministic cross-platform guard blocking root traversal & system/history harvesting
_FORBIDDEN_CMD_RE = re.compile(
    r"(?i)(?:^|[;&|()\s])("
    r"journalctl|dmesg|lastlog|ausearch|"
    r"ps\s+(?:aux|-ef|-e)|"
    r"find\s+/(?:\s|$)|"
    r"cat\s+.*(?:\.bash_history|\.zsh_history|/etc/shadow|/etc/passwd|/var/log)"
    r")(?:\s|$)"
)

_SENSITIVE_PATHS = (
    "/var/log",
    "/proc",
    "/sys",
    "/etc/shadow",
    ".bash_history",
    ".zsh_history",
    ".ssh",
    ".gnupg",
)


def validate_workspace_command(command: str, workspace: Path) -> str | None:
    """Returns a rejection reason if `command` escapes workspace or inspects host logs/state."""
    if _FORBIDDEN_CMD_RE.search(command):
        return "blocked: system log, process table, or root filesystem inspection is prohibited."

    ws_resolved = workspace.resolve()
    try:
        tokens = shlex.split(command, posix=True)
    except ValueError:
        tokens = command.split()

    for tok in tokens:
        cleaned = tok.strip("\"'`;|&()")
        if any(s in cleaned for s in _SENSITIVE_PATHS):
            return f"blocked: access to sensitive host path '{cleaned}' is prohibited."
        if cleaned.startswith("/") and not cleaned.startswith(("/dev/null", "/tmp")):
            try:
                target = Path(cleaned).resolve()
                if not (target == ws_resolved or ws_resolved in target.parents):
                    return f"blocked: absolute path '{cleaned}' is outside workspace '{ws_resolved}'."
            except OSError:
                return f"blocked: invalid path '{cleaned}'."
        if ".." in Path(cleaned).parts:
            candidate = (ws_resolved / cleaned).resolve()
            if not (candidate == ws_resolved or ws_resolved in candidate.parents):
                return f"blocked: path '{cleaned}' escapes workspace '{ws_resolved}'."
    return None


def build_isolated_env(workspace: Path) -> dict[str, str]:
    """Builds a minimal, secret-free environment rooted inside the workspace."""
    scratch_home = workspace / ".verbix" / "home"
    scratch_tmp = workspace / ".verbix" / "tmp"
    scratch_home.mkdir(parents=True, exist_ok=True)
    scratch_tmp.mkdir(parents=True, exist_ok=True)
    return {
        "PATH": os.environ.get("PATH", "/usr/bin:/bin"),
        "HOME": str(scratch_home),
        "TMPDIR": str(scratch_tmp),

        "PIP_PROGRESS_BAR": "off",
        "TQDM_DISABLE": "1",
        "LANG": os.environ.get("LANG", "C.UTF-8"),
    }
